
# BIDWESH NLP Midterm Project

## Project Title
Regional-Aware Bangla Hate Speech Detection Using Classical NLP and Machine Learning Techniques

## Dataset
BIDWESH: A Bangla Regional Based Hate Speech Detection Dataset

## Regional Dialects
- Chittagong
- Noakhali
- Barishal

## Classification Task
Binary Classification:
- 1 = Hate Speech
- 0 = Non-Hate Speech

## Dataset Source
Fayaz et al. (2025)

DOI: https://doi.org/10.17632/bpkrvf882k.1

Source: Mendeley Data, Version 1
